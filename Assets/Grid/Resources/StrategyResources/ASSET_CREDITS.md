# Adventure resources (32 x 32)

These are licensed, human-authored assets from OpenGameArt; no generated artwork is used. All seven game PNGs are exported on the same 32 x 32 transparent canvas with Point filtering. Original Unity GUIDs are preserved.

| Resource | Original artist / asset | Source / license | Adaptation |

| Wood | Saint11, Wood.png | https://opengameart.org/content/resouces-pack-1 — CC0 | Trimmed, reduced to 32px / 32 colors |
| Ore | Saint11, Minerals.png | Same source — CC0 | Trimmed, reduced to 32px / 32 colors |
| Mercury | Henrique Lazarini / 7Soul1, P_White01.png | https://opengameart.org/content/496-pixel-art-icons-for-medievalfantasy-rpg — CC0 | Removed atlas border, fit to 32px |
| Sulfur | Jaqueline Martin / Chibizilla, gold.png (yellow mineral used as sulfur) | https://opengameart.org/content/handdrawn-resource-icons-75x75px — CC BY 4.0 | Reduced to 32px / 32 colors |
| Crystal | Jaqueline Martin / Chibizilla, ruby.png | Same source — CC BY 4.0 | Reduced to 32px / 32 colors |
